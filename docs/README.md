# Tài liệu dự án

| Thư mục | Nội dung | Phụ trách |
| --- | --- | --- |
| `requirements` | SRS, phân tích nghiệp vụ, user story (bản xuất PDF/MD) | SV01 |
| `design` | Sơ đồ kiến trúc, ERD, sequence diagram, BPMN | SV01, SV03 |

| `testing` | Kế hoạch kiểm thử, ma trận truy vết, báo cáo kiểm thử | SV08 |
| `operations` | Hướng dẫn triển khai, sao lưu và khôi phục | SV07 |
| `reports` | Báo cáo cuối kỳ, báo cáo cá nhân, slide | Tất cả |
| `samples` | Dữ liệu mẫu CSV/JSON dùng chung | SV06 |
